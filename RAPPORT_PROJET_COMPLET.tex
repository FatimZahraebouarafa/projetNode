\section{Vue d'ensemble du projet}

\subsection{Description}

\textbf{Rabta} est une plateforme web moderne de gestion de rendez-vous professionnels qui connecte les utilisateurs avec divers professionnels (médecins, infirmiers, kinésithérapeutes, professeurs, avocats, etc.). La plateforme offre un système complet de prise de rendez-vous avec authentification sécurisée et gestion basée sur les rôles.

\subsection{Objectifs}

\begin{itemize}
    \item \textbf{Faciliter la prise de rendez-vous} entre utilisateurs et professionnels
    \item \textbf{Gérer les disponibilités} des professionnels
    \item \textbf{Assurer la validation} des inscriptions professionnelles par un administrateur
    \item \textbf{Sécuriser les échanges} avec authentification JWT
    \item \textbf{Permettre la communication} via un système de messagerie intégré
\end{itemize}

\subsection{Utilisateurs cibles}

\begin{itemize}
    \item \textbf{Utilisateurs finaux (USER):} Personnes recherchant des services professionnels
    \item \textbf{Professionnels (PROFESSIONAL):} Fournisseurs de services (santé, éducation, juridique)
    \item \textbf{Administrateurs (ADMIN):} Gestionnaires de la plateforme
\end{itemize}

\section{Architecture technique}

\subsection{Architecture globale}

L'architecture suit un modèle trois tiers (3-tiers):

\begin{enumerate}
    \item \textbf{Tier 1 - Présentation:} React Frontend (Port 3001)
    \item \textbf{Tier 2 - Logique métier:} Express Backend avec Controllers (Port 5000)
    \item \textbf{Tier 3 - Données:} MongoDB (Port 27017)
\end{enumerate}

\subsection{Pattern architectural}

\textbf{Architecture 3-tiers:}
\begin{itemize}
    \item \textbf{Tier 1:} Présentation (React Frontend)
    \item \textbf{Tier 2:} Logique métier (Express Backend avec Controllers)
    \item \textbf{Tier 3:} Données (MongoDB)
\end{itemize}

\textbf{Pattern MVC adapté:}
\begin{itemize}
    \item \textbf{Models:} Définitions des schémas Mongoose
    \item \textbf{Views:} Composants React
    \item \textbf{Controllers:} Logique métier dans le backend
\end{itemize}

\subsection{Communication}

\begin{itemize}
    \item \textbf{REST API} avec format JSON
    \item \textbf{Authentification JWT} avec Bearer Token
    \item \textbf{CORS} activé pour les requêtes cross-origin
    \item \textbf{Proxy} configuré dans le frontend (http://localhost:5000)
\end{itemize}

\subsection{Middleware d'authentification}

\begin{itemize}
    \item \textbf{Middleware protect:} Vérifie la présence du token JWT, décode le token, charge l'utilisateur depuis la DB, attache req.user
    \item \textbf{Middleware adminOnly:} Vérifie que req.user.role === 'ADMIN'
    \item \textbf{Middleware userOnly:} Vérifie que req.user.role === 'USER'
    \item \textbf{Middleware professionalOnly:} Vérifie que req.user.role === 'PROFESSIONAL'
\end{itemize}
